## Phase 8：策略消融实验（3 题 × 3 配置）

| 文件 | 说明 |
|---|---|
| `phase8_20260921_201623_report.md` | **主报告**（可直接阅读的对比分析，含方法与局限） |

| `phase8_20260921_205431.csv` / `.json` | 同上，结构化数据 |

主报告的核心结论：

- 反思循环把事实量从 35 提到 118（**3.4 倍**），成本只增 2.6 倍 → 性价比最高
- 证据越多，忠实度评分反而越低（0.883 → 0.750），说明"多搜"和"引对"是两个独立问题
- 原以为"本地知识库没用"，排查后发现是自己的融合算法有 Bug（跨来源各自归一化 + 40% 硬配额），
  修复后同一道题事实数从 106 提到 **141**

复现：`python eval_research.py --ids T1 T3 T5`

## ⚠️ 关于离线自检产物

`python eval_research.py --offline` 用的是**假模型 + 假搜索**，产出的是构造数据。
这类产物**不会留在本目录**（跑完请自行删除或放到 `outputs/`），以免被误当成真实结果。

## 这些数字是怎么来的

- **客观指标**（轮数、事实数、引用数、字数、Token、成本、耗时）来自程序内置插桩，零额外成本
- **引用准确率**通过真实 HTTP 请求逐条核验，并把「站点反爬 403」与「链接真失效 404」分开统计
- **报告质量**由自研 LLM 裁判打分（忠实度/相关性/覆盖度/结构性），
  忠实度的判定方式是拿报告正文与它自己引用的事实清单逐条比对

完整的方法与局限见 `eval_research.py` 顶部注释，以及 `phase8_*_report.md` 的「六、方法与局限」。
